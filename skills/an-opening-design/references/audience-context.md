# 受众资料怎样参与开头、道具与升华

## 读取范围

这三个环节都判断目标观众能否理解、是否感兴趣，以及表达是否适合其倾向。先遵循 [Mastra 原生运行与资料协议](mastra-runtime.md)，使用本轮明确受众与当前认证用户已注入的 `positioningReport`；原文件入口已映射为 Resource Working Memory，不读取或生成 `positioning/定位报告.md`。本轮明确提供且授权的本人报告或附件，仅在正文实际可读、归属明确时优先；没有文件／附件读取工具时不能假称读过。报告不是本包方法文件；缺少定位时按当前材料和已有受众继续，不启动定位访谈，不扫描其他项目。

第3／4／5／10／13项在当前 Schema 中分别为 `coreAudience`、`audienceNeeds`、`coreValue`、`personaAndRelationship`、`boundariesAndOpenQuestions`；只用各章中与受众直接相关的部分，不因完整记忆已注入而扩大使用范围。

只提取与本次观众判断相关的信息：第3项核心用户的知识熟悉度、兴趣、生活与文化经验；第4项已知需求、顾虑和认知习惯；第5项观众期待的价值；第10项与观众交流的关系和距离；第13项表达与披露边界。在这些段落与本轮材料中，按需使用已有的观看时刻、场合和注意力状态，圈层熟悉的语言与生活细节、容易误读之处，以及看完具体能得到的理解、表达、体验或行动帮助。缺少这类信息仍可继续，推演不冒充已观察到的群体习惯。其他已有资料仅在直接帮助理解本次受众时使用，不强填13项。理解能力不能由年龄、职业或学历标签直接推定，已知偏好不等于每个观众都如此。

读取定位时保留原话与采用状态，不把创作内容写回为用户已经认领的档案信息。作者本轮的观点、情绪和绝对表达不需要被外部事实批准；故事、对白和情境可以创作，不逐项标待验证。受众想要的效果不证明产品能实现，效果承诺与作为真实证明的案例仍须有依据。上传材料不自动属于本人；归属不明不当作本人定位，也不影响先处理当前材料。当前明确修正优先于旧报告，只在必要歧义确实影响本次结果时澄清。已有信息足够就直接使用，不新增受众表、选词确认或必填问卷。

## 本条受众的需求与决策起点

在上述只读范围中承接报告已有的主攻层与另外两层：本条主要面向哪层、这些人已经决定什么、尚未决定什么，以及适用于本条的公开内容和表达边界。本轮指定优先，未指定时从已采用主攻层理解；缺少新信息仍按现有材料继续，不追加三层问卷，也不补成已确认事实。决策阶段不等于文化程度、知识水平或信任程度。本条内容承担吸引、持续关注、建立信任、参与或适用时的商业承接，是另一项判断，不与层次固定对应；只承接本轮已知目的和获准受众信息，不为确定账号作用扩大读取范围或追加前置问题。观众具体所得与账号目的分开，不把“让人关注我”当成观众价值。

把起点落实到实际构思：面向“选择哪种乐器”的开头不能默认观众已经在找钢琴老师；道具的比喻需要帮助该层理解，而不提前强推服务选择；升华不能把普通生活体验提高为医疗建议、疗效或其他无依据的因果承诺。按报告已确认的公开内容策略吸引对应人群，不为显示专业强加项目讲解，不把内容标签当成效果依据。未知的效果或真实案例依据只限制依赖它的证明性表达，单条换层不写回长期定位。

## 信息必须影响具体选择

- **开头**：据受众的关注对象、知识和欲望选择能认出并理解的词语与观看理由；已有观看情境可帮助判断切入速度与信息负担，圈层细节可帮助识别可信表达与误读；每种构思仍完整探索，不能按定位提前删法。检查真正说出的语言是否精准、构思法是否成立、文案是否独立成立、场景氛围灯光是否与文案一致、正文是否兑现；受众适配不能扩大承诺。
- **道具**：检查观众是否认识物品及其用法，能否从可见细节理解比喻或承载关系，是否关心这种呈现；结合已有注意力条件判断映射是否容易被看见，考虑同一物品在不同圈层中的含义。必要时补一个简短示范或改用熟悉物品；不把陌生、新奇自动当兴趣，也不把比喻当事实证明。
- **升华**：按受众已有理解、感情关切与价值倾向，选择解释层次、概念和情感表达，让新增内容带来具体的理解、表达、共鸣或审美所得；圈层误读用于校准是否传达原意，不用来抹平作者立场。能带来理解或感受增量且保持作者立场、逻辑方向、情绪与力度才采用；不为迎合受众、追求客观或积极导向歪曲原意，也不自动平衡、降温或和解。

开头的这些判断融入实际文案与画面，留在内部逐案检查，不追加构思说明；道具与升华融入已有适配理由或增补内容，不增加统一评分表、强制报告栏目或新的创作站点。已在上下文且来源、归属和版本可靠的受众信息可以使用，不反复索取；旧摘要不能冒充当前档案读取结果，也不能提供虚构的效果与真实案例依据；这不限制本轮普通创作。

## 风格与维护边界

受众适配不等于模仿创作者个人口吻。这三个环节仍不读取、套用语言风格档案、样文或其摘要；本轮明确的语气、句式和范围正常执行。定位只读用于受众判断，不比较或主动提议维护长期档案，不保存本次创作推断为永久受众结论，不写入技能包。用户另行明确要求查询或维护定位、风格时，作为独立任务衔接实际可用方法。
