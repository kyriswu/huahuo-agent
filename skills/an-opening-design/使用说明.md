# 开头处理｜使用说明

按已有受众信息理解观看情境、注意力和期待所得，落实到关注词、理解负担与继续看的理由；不额外采集定位，也不读取个人语言风格档案。

版本：1.4.0。内部标识：`an-opening-design`。中文展示名为“开头处理”。

本技能使用作者确认的十六种并行构思法，完整方法随包提供。

## 用途

提供目标用户、主题、正文核心和当前素材后，按固定顺序执行全部十六法，每法三个候选，共四十八案。每法单独一张表，只有“文案”“画面”两列、三行候选。文案独立体现构思，关键对象与关系写进话里；画面建议只写相配的场景、氛围与灯光，不写道具清单，不提供声音或节奏建议，不附构思说明。每案的语言开头都要有能让本条目标用户认出欲望、处境或具体关注对象的精准词语，不能只放在说明或画面里。独立调用默认在十六张表、四十八案完成后停止，不评分、不排序、不推荐，由使用者自行选择；完整主流程的分步与一次模式按下述调用合同交付。只要求诊断或已选定某项继续修改时，尊重该范围。合稿、道具或情境引起的回改后，实际语言仍须精准，所选构思法的成立条件、文案独立成立、画面与文案一致和正文兑现也须重新检查；词还在、接得顺不能代替这些条件。

## 定位与语言风格

“开头处理”结合本次原稿、主题、素材、明确要求和包内方法，按 [受众资料协议](references/audience-context.md) 读取已授权当前项目定位中的相关受众信息。受众的兴趣、理解基础、关注词语和期待价值会用于设计语言钩子，开头承诺仍须由正文兑现。本轮明确受众与范围优先；没有定位时按本轮材料继续，不要求重新访谈，只有关键缺口才必要补问。

仍不读取或套用语言风格档案，也不从其摘要或其他技能间接引入语言习惯。本轮直接提出的语气要求正常使用。读取受众不启动定位维护、不提议更新或自动写回长期档案；另行要求档案维护时按独立任务处理。

本技能也供IP人设视频第七站和引流获客第八环节调用，同样执行完整十六法。分步交四十八案后询问选择，选定或委托后由主流程同轮交完整终稿，不再确认合稿；一口气完成在内部生成、检查、择优并整合，默认只交完整终稿，不等待选择。专业依据见 [开头执行规则](references/开头执行规则.md) 与 [开头处理方法](references/开头处理方法.md)，交接见 [完整流程调用合同](references/full-workflow-handoff.md)。

## 导入与使用

本版已作为项目内的 Mastra 原生 Skill 接入 HuoX，标识为 `an-opening-design`，中文名为“开头处理”。登录 Studio 后选择 HuoX，直接说“用开头处理帮我设计开头”并提供本轮材料；不需要另行导入或安装插件。框架按需加载 `SKILL.md` 和包内方法。运行与定位记忆映射见 [Mastra 原生协议](references/mastra-runtime.md)。

默认在对话中交付开头，不改动原始素材文件；独立请求只处理本轮要求的开头生成、改写或诊断；完整主流程调用按已有授权整合全文。

## 可以直接发给技能的内容

> 目标用户是写完稿却迟迟不敢录视频的新手创作者。正文核心：先录一个不发布的练习版本，回看时只挑一个能改的具体问题，修改后再录一遍；练习不能保证播放量。素材只有桌前的我、手机、纸稿和笔，没有学生案例、旧视频或历史数据。请设计开头，不编造我的经历，也不用替我选择。

使用时可核对：是否按固定顺序给出十六张两列表格、每表三案共四十八案，是否每案文案独立体现方法、画面只写场景氛围灯光，同法三案是否实质不同，是否每案实际语言都有受众能理解且在意的精准欲望词或关键词，开头承诺能否由正文兑现，是否保留正文核心；独立调用是否按范围停止，分步主流程是否询问选择并在选后交完整终稿，一次主流程是否内部择优并直接交完整终稿。

## 个人资料与作品

已保存的用户定位由原生 Resource Working Memory 提供；本技能只使用其中受众相关信息。作品默认交付在当前对话，不自动保存到用户项目文件或长期记忆，不写入技能包。

## 创作中的材料保真

本技能以作者意图与表达自主性为先。尊重用户的立场、情绪、判断和表达力度；除非用户要求求证或批判，不自动纠偏、降温、平衡、道德化或强行成长、和解。普通故事、人物、对白、心理、比喻和情境可以围绕表达目的创作，无需逐项求证或标注待验证。依据要求集中于效果承诺和作为真实证明使用的案例；不得伪造研究、名言出处或实测记录来为观点背书。用户明确要求只整理原稿、只改局部或保留指定内容时仍按范围执行，不能借创作换掉作者的观点。

材料保真首先检查有没有改掉你的观点、情绪和力度；不会因为“人性本恶”“世界没有好人”过于绝对就改成中性结论。事实依据检查只进入相关的效果承诺、真实证明案例和具名证据，不变成普通创作的统一门槛。
