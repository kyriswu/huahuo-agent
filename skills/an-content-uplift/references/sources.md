# 方法来源与适用范围

本包依据教师提供的《金句提炼方法论》和《理论拔高方法论》，结合内容升华的使用流程组织。执行需要的方法已整理在包内。本文介绍教学来源与当前适用范围，不是运行时需要读取的外部文件清单。

## 金句提炼方法论

原文题名：《金句提炼方法论：内容分类、认知压缩与句式适配》。

实际采用的关键方法：

- 原意核、材料身份、句子任务、认知内核和关系结构。
- 观点、机制、定义、方法、情绪、故事、事实资讯的不同成句标准。
- 句式服务真实关系；保留必要因果、条件、范围和具体承载。
- 排比、对称、对偶、对比、递进与长短句的适配；自然流畅与强修辞的区别。
- 候选的保真、必要信息、套话、独立理解和朗读检查。

在本包中，细分类型用于内部方法选择；学生入口按理性、感性与混合部分组织。理性涵盖观点、机制、定义、方法和事实影响，感性涵盖感受和故事意义；二者不按主题词机械划分。

## 理论拔高方法论

原文题名：《理论拔高方法论：跨学科解释、尺度上升与思想综合》。

实际采用的关键方法：

- 先保护原意核，再从具体入口提出深层问题。
- 跨学科召回并筛选真正有新增解释力的理论，不用数量凑深度。
- 主解释、跨尺度补充与连接关系；条件与边界服从原文和任务，反方仅在用户要求求证或批判时采用。
- 保留作者原意与表达力度；具名理论和真实证明依据不得伪造，普通故事与解释可以创作。
- 形成综合认识，再回到原文处境和自然表达；保留张力和条件。
- 不虚构学者观点、研究、数据，不根据短文诊断人格或自动归因于结构。

本包保留深度分析的要求，不增加轻、中、重档位。分析服务当前理性部分，不把每种素材都写成社会哲理，不默认展示理论报告。

## 当前交付规则

依据用户最新有效文案，内部识别理性、感性与混合部分；理性部分补充理性金句与理论拔高，感性部分补充感性金句，优先使用有内容递进的排比。已有文案直接处理，没有材料时才请用户发送；本轮明确范围优先。

首轮按原文位置给出可直接使用的插入建议，不展示内部分类、理论分析报告或首选与备选清单。给出建议后询问采用哪些、修改哪些；明确的采用与修改指令即触发整合，要求先看改法时先修订。基于最新原稿和最新确认内容交付完整稿，保护无关段落，避免重复插入；采用文案不等于授权覆盖本地文件或写入长期档案。

本技能可单独使用，结合最新原文、本轮要求、包内方法，以及按 [受众资料协议](audience-context.md) 读取的授权当前定位受众信息，判断解释深度、情感与价值表达是否合适；作者立场、情绪、表达力度及明确的原文限制仍须保留，不以追求客观自动纠偏或加平衡。无定位时按本轮材料继续，仅关键缺口必要补问。不读取或套用语言风格档案及其摘要，不重启定位访谈，也不检查维护差异、提议更新或自动写回长期档案。

原包的宿主文件清单与内容指纹不适用于适配后的文件。本版来源、保留与改动范围见 [迁移来源说明](source-map.md)；不沿用旧 `source-map.json` 的指纹，也不将来源说明当作内容质量或创作效果证明。

创作以作者意图与表达自主性为先：允许发展故事、人物、对白、心理与比喻，依据检查集中在效果承诺与作为真实证明使用的案例；不编造研究或名言作背书，不把普通创作变成真实性审查。
