# 感性金句与排比表达

本参考供安先生内容升华 skill 内部使用。它从《金句提炼》的情绪、故事、语言与保真方法整理而来，已包含独立使用所需规则。

用户发来文案后，直接在感性部分寻找可补充的位置。分类、分析与审计在内部完成，首轮按原文顺序给出锚点和可直接使用的感性金句。不要在给建议前追问模式或安排访谈；给建议后询问采用与修改哪些，确认后按主技能的流程整合进原文，交完整稿。

按 [受众资料协议](audience-context.md) 使用本轮受众与授权当前定位的相关信息，理解他们关心的关系、感受与价值倾向，选择能被理解的情感承接。无定位时按本轮材料继续，仅关键缺口必要补问；不读取语言风格档案。受众判断用于创作，不自动成为已验证结论；也不能替作者决定应该感到什么。

## 1. 感性部分在做什么

感性不等于悲伤、煽情或抽象抒情。喜悦、期待、尴尬、轻松、矛盾、怀念、庆幸和克制都可以成为感性表达。

| 内容 | 主要任务 | 提炼时保留什么 |
| --- | --- | --- |
| 直接情绪 | 准确命名一种感受 | 对谁、因何、在什么处境下产生，以及情绪强度 |
| 矛盾感受 | 说清两种同时存在的心情 | 希望与顾虑、靠近与退让等真实张力，不替作者消除矛盾 |
| 经历片段 | 让一个时刻更有感受 | 原文已有的动作、场景、物件或时间关系 |
| 故事感悟 | 从变化中回收意义 | 人物起点、关键选择、前后变化，以及具体承载 |
| 关系表达 | 说清关系中的期待与落差 | 双方已知行为、作者的真实感受、尚未知道的对方动机 |

不要看到故事就自动补人生道理。先判断该处需要被记住的是感受、变化还是意义。故事里已经明确提出的方法或机制，则作为理性部分另外处理。

## 2. 找到作者的情绪内核

在内部确认：

- 情绪对象是什么，触发它的原文处境是什么？
- 作者想被理解的，究竟是失去、落差、等待、犹豫、被看见，还是其他感受？
- 原文有没有两种同时成立的情绪，而不只是单一的喜或悲？
- 哪一个现成细节最能承载这种感受？
- 原文的语气有多强，补充后是否仍像同一个人在说话？
- 这类受众能否理解该感受的触发处境，所用表达会不会变成对他们的评判或劝导？相关判断有何本轮材料或受众信息支撑？

命名情绪要贴近作者想表达的意思，不替作者决定隐秘欲望或价值立场；人物心理与对白可以创作。作者明确要说“对方从未爱过”时，不因为 AI 认为证据不足改成“也许只是表达方式不同”。

一句感性金句应让感受更容易辨认，可以留白，但不能用含混冒充深刻。写出一层具体的关系或矛盾，比增加一串形容词更有价值。

受众关切用于选择怎样承接原文已有情绪，不用于制造情绪。可以让已有关系或物件更容易被观众理解，但不能仅因某类观众重视家庭、独立或成就，就加入原文没有的牺牲、决裂或胜负立场；原文仍在犹豫时，不能为迎合其价值偏好替作者宣布答案。

## 3. 用具体承载发展感受

优先接住原文的关系、物件、动作、地点和时间，可围绕同一情绪创作新细节、对白、心理、人物或经历。普通创作无需另外取得“允许虚构”的授权，不逐项注明“创作设定”或“待核实”。第一人称也可以是作品的叙述声音，不要求每个动作都来自作者履历。

新增内容须服务原文表达：原文只是期待又紧张时，不自动把动机换成“为了妈妈争气”；作者不舍时不强行补写释怀，作者愤怒时也不替他找宽恕的理由。用户明确说“只整理”“不加新事”“这个人物不能改”时，按该范围锁定内容。

可以用物件回收情绪，以比喻、动作或新写对白让感受可见，也可以设计人物的内心与时间变化。不要把这些新写内容当作原文引句或写入用户长期档案。作为真实证明使用的客户故事、效果案例和研究背书须有依据，不能用“这是创作”伪造证明。

## 4. 感性金句的组织方式

从具体关系选择句式，不从固定套话反推感受。

| 组织方式 | 适用位置 | 使用要求 |
| --- | --- | --- |
| 感受命名 | 情绪已出现但还说不清 | 命名当前处境，不解释所有人 |
| 前后对照 | 原文或本轮设计有态度与认识变化 | 对照服务同一命题，不擅自把未释怀写成已和解 |
| 意象回收 | 前文已有或本轮创作出的关键物件与动作 | 保持物件、人物和情绪关系连贯 |
| 矛盾并置 | 两种感受同时存在 | 不把一种感受贬低成虚假 |
| 时间关系 | 内容有等待、延迟、告别或变化 | 保留作者对时间与命运的判断，不自动把“永远”改成“暂时” |
| 短句落点 | 前文已有足够铺垫 | 落点属于当前内容，避免万能鸡汤 |

一句金句可以是几句短分句组成的完整表达。先保证情绪可辨、对象清楚，再调整停顿、重音与记忆点。不要为了“像金句”强制使用“不是……而是……”或“你以为……其实……”。

## 5. 多用有内容递进的感性排比

优先在合适的位置使用排比。排比可以累积情绪，也可以把同一种感受展开成不同侧面；每一分句必须增加一点内容。

可选推进：

- **感受层次**：从当下反应，到心里的矛盾，再到真正舍不得的对象。
- **原有细节**：由原文的不同动作或物件逐步累积，最后回收同一种感受。
- **关系层次**：从行为，到期待，再到彼此理解的落差；后两层服务原文情绪，可写人物心理与对白。
- **前后变化**：依次承接原文已有的过去、转折和现在。

可以新增服务同一情绪的故事细节，但不为凑三句改变人物动机或情绪方向。不要把“很想你、特别想你、真的想你”当成三层内容；也不要把“委屈、心酸、难过”仅仅排成一串。

结构可以相近，句长不必一样。几个分句之后可以用一句短句收住，也可以让最后一分句落在最具体的对象上。读起来要有呼吸，不要每一处补充都重复同一种节奏。

克制、欣喜和轻松也可以形成排比，不必一律升级为眼泪、崩溃、孤独或遗憾。排比增加的是表达层次，不能擅自提高情绪强度。

## 6. 故事中的感悟如何长出来

内部依次检查：

1. 原文人物原先处于什么状态？
2. 哪个已提供的动作、选择或事件带来变化？
3. 结尾因此重新照亮了前面的哪个细节？
4. 感悟是否真能由这个故事支持，而不是任何故事后都能接的道理？

从故事中回收意义时，保留一点具体承载。不要把原有复杂性抽掉，只剩“经历都是成长”“所有相遇都有意义”等无差别结论。

未完成的故事可以保留未完成。作者还在犹豫，不替他宣布释怀；人物还没做选择，不替他补上勇敢转身；一次失败不必转成命运馈赠。

## 7. 混合段落的协同

同一段既有感受又有判断时，可以在同一锚点下分别给出感性金句与理性补充，或选择不同的自然停顿位置。仍按原文顺序组织，不能先把整篇理性内容列完，再把感性内容列完。

理性部分说明关系为什么形成；感性部分让读者认出人在其中的体验。两者各做一件事，不用理论证明情绪“合理”，也不用情绪强度代替论证。

如果一条句子已兼顾两者，不必硬拆两条同义句。也不要在一个短段落里同时堆满判断、理论、故事感悟和排比高潮。

对原文中已有明确观点的感性段落，新增感性表达应与该观点相容。对尚无明确立场的情绪表达，不以补充为名替用户建立全新的价值立场。

## 8. 虚构示意与反例

以下为教学示意，展示怎样服务作者的情绪与动机；实际生成围绕本轮文案发展，不机械套用。

**假设原文：**“明天第一次上台分享，我准备了很久，很期待，也怕自己讲不好。”

**可补充的感性金句：**想把话说清楚，想让准备被听见，也想让明天的自己，比今天多一点敢开口的勇气。

这里由表达、被理解到行动愿望推进，保留期待与担心，没有增加曾经失败、整夜失眠或台下某位亲人的新事实。

**改变作者动机的反例：**“练到凌晨三点，哭湿了枕头，我终于决定为坐在台下的妈妈勇敢一次。”

问题是没有承接原文的期待与紧张，直接替作者改成悲壮的亲情动机。创作时间、动作和人物本身允许，但应服务作者原意；用户主动选择亲情动机后才可沿那个方向展开。

**假设原文：**“搬家时，我把用了十年的旧杯子也装进了箱子。东西没多少，还是收拾了很久。真要离开时，才发现自己这么舍不得。”

**可补充的感性金句：**杯子不大，装得下十年的日常；箱子不大，却让这次告别有了分量。

这里的“装得下日常”是清楚的比喻，并非新增实物；但原文如果并无告别或不舍意味，就应改用更中性的表达，不能仅凭收拾得久断定情绪。杯子的来历可按创作需要设计，但不要借来历把不舍偷换成原文未表达的怨恨或释怀。

**无效排比示意：**“离开很难，告别很难，分开也很难。”三个近义词没有提供新感受。改写时需要回到原文已有的不同细节；没有足够细节，写一句准确的话即可。

**受众适配的虚构对照：**原文若是“我想照顾家人，也想保留一点自己的时间”，本条面向同样在协调这两种需要的人，可以补“惦记家人的需要，也惦记自己的生活，两份心意都还在。”它承接原有张力，没有要求观众选边。若为迎合“家庭责任”倾向写成“真正爱家的人就该放下自己”，或为迎合“独立”倾向写成“只有离开家人才能找回自己”，都替作者新增了价值裁决，不能作为受众适配通过。

## 9. 交付前审计

- 这句话是否承接作者的感受，还是替作者决定了另一种动机？
- 情绪对象、关系和力度是否保持？有没有擅自强化或弱化作者对时间、人性和世界的判断？
- 新写的第一人称经历、人物心理、对白和意象是否服务原意，是否违反用户明确的不增写限制？
- 有没有把普通创作标成待验证，或索要并不必要的真实经历证明？
- 有没有把新写故事包装成真实效果案例或把虚构研究当证据？
- 排比分句是否增加不同侧面，新增事件是否服务同一情绪而非机械凑数？
- 原稿克制时，是否被擅自改成沉重、悲壮或煽情？
- 感悟是否来自故事，是否替未完成的经历强行收尾？
- 混合段落中，感性与理性补充是否各有作用，是否互相重复？
- 换成任何一个主题都适用的句子，是否缺少原文辨识度？
- 插在该锚点后，是否与前后文衔接，是否提前透支后文的情绪落点？
- 读出来是否像自然说话，是否存在过长排比或连续套话？
- 情感与价值表达是否适合本条受众的已知处境，是否保留原文立场、关系和分寸，而不是迎合倾向、制造焦虑或强行劝导？

发现问题先删改再交付。没有值得增加的感性认识时，保留原文即可；不必每段都补、不必凑够几个位置，也不必靠堆砌细节满足排比偏好。
