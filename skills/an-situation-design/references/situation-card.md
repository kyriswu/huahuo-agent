# 情境卡与诊断

《4-5 情境化思维》第 002 张课件的十二个栏目是完整性检查，不是要求所有视频都配齐人物和物品。内部可记无配角、无道具或无画外声，普通人物、经历与对白可以创作，无需逐项标待验证；用户明确限制与真实证明的依据另行遵守。保持元素指向同一件事，不把内部检查记录默认输出。

默认四方案时，先核对两案直接对镜头／观众说、两案现场互动由第三方记录，再将下面的骨架与十二项用于每一案的内部检查；四案均展开后，按 [四方案配比与人群比较](four-situations.md) 比较受众、优点和缺点。用户指定局部诊断时只使用相关部分。

默认对外以“你”称呼创作者，第三方记录同样如此；台词和配角保持各自人称。方案阶段每案写情境和目的、前因与开场、交流与拍摄关系；其中开场必须给出可直接使用的匹配台词，用语言交代必要关系与前因；不附推进收尾、拍摄条件或事实边界，也不把这些内容改名加入默认交付。

## 十二项内部检查

| 图中栏目 | 设计时需要落到的具体信息 |
|---|---|
| 环境 | 地点、时间条件及其为何影响这件事；不只是好看的背景。 |
| 前因 | 镜头开始前的触发事件，以及观众从哪个痕迹、动作或声音知道它。 |
| 人物 | 谁、处于什么身份和关系；服务作者命题，可创作角色，不逐项贴真实性标签。 |
| 切入时间 | 事件进行到哪一个动作或决定时开拍；区别于“晚上八点”等钟表时间。 |
| 此刻情绪 | 由前因与目的产生的状态，以及可观察的身体表现；不只填形容词。 |
| 行动（目的） | 人物对具体对象做什么、想得到什么回应或改变；区别于账号目标。 |
| 对抗／互动的事物，对谁说／对谁做（观众／其他人物） | 谁或什么回应、阻碍、牵动人物；说话与行动对象分别是谁。可以是内心、环境或群体。 |
| 谁在拍 | 直接对观众说可自拍或由他人掌镜；第三方记录须列实际或拟需拍摄者。固定机位自拍不能冒称第三方。另写主要交流对象与观众位置，不仅凭谁拿手机归类。 |
| 道具（指明场合的道具） | 能指明地点、任务、前因或关系的物品与使用痕迹；没有作用就不加。 |
| 配角（有／无） | 是否存在、是否入镜、在关系中做什么；不因填表而虚构协拍资源。 |
| 画外空间／氛围／声音 | 画外有什么及其可见或可听的依据；空间和声音是否与事件连续，避免无关氛围堆叠。 |
| 拍摄方式 | 手机如何放、关键动作如何进入画面、必要的景别或镜头变化；满足最低可拍条件即可。 |

## 时间前后想象（内部检查）

用一条连续链检查，不能只写孤立的开头：

**之前的事 → 当下残留的证据 → 镜头切入的动作 → 推进与回应 → 结束后仍会继续的生活。**

- 前向想象：观众依据什么推断“刚刚发生了什么”？必要背景是否已经足够？
- 后向期待：观众为何想看“接下来会如何”？本段是否兑现或推进，而不是故意截断答案？
- 结束余味：这段结束后，人物还会继续做什么、关系还可能怎样延续？无需把每层意义用台词总结。

默认不将这条行动链或结束余味作为交付字段；用户明确要求时再用“之前／之后”解释，避免方位术语造成歧义。

## 常见误判与最小修正

| 方案问题 | 修正方向 |
|---|---|
| “在车里讲亲子关系” | 补出发生中的事件，例如接到孩子后，回应他刚提出的问题；仅有车内空间不成立。 |
| “在书房，情绪低落，讲选择” | 找到造成低落的前因与正在做的决定；用检查、收起、放回等动作落实，不用配乐代替前因。 |
| “展示我的专业”被当作人物目的 | 改为此刻想把谁的哪个问题解决到什么程度，让专业由行动体现。 |
| 画面有生活气息便断言有钩子 | 分开说明氛围作用与未完成问题；没有后者也可保留情境价值。 |
| 每条都加入吵架或意外电话 | 回到主题中的阻力、犹豫、关照与等待；删掉与内容无关的刺激。 |
| 对着空处说话却没有对象或回应依据 | 明确是演绎角色、真实画外对象还是对观众说；让视线和交流方式一致。 |
| 镜头外安排多人，但实际只有一个人 | 直接对观众说的方案可单人拍；第三方记录方案在内部识别协拍资源是否已具备，对外只描述拍摄关系，不列资源缺口或声称当前已能拍。只有用户明确要求全部单人方案时才覆盖配比，不用固定手机伪称第三方记录。 |
| 所有方案都像偷拍，人物必须忽略镜头 | 核对“2＋2”：两案明确对观众说；两案现场互动、第三方记录，也可知情拍摄。 |
| 把“刚发生，现在对你讲”排除出情境 | 补清刚才的触发与此刻对观众的具体表达目的；讲述本身可成为行动。 |
| 为留白藏掉人物关系或关键前因 | 用一句称呼、一个状态或现场声提供最低识别线索，再保留动机和情感的余地。 |

## 生活切片积累模式

用户要整理素材时，在十二项中先记录确实知道的内容，未知留空；再加“为什么值得留下”和“可迁移到什么主题／人物关系”。观察记录与后续改编提案分开。优先保留决定、等待、克制、修改、交付等关系发生变化的瞬间，也可保留有独特氛围的日常，不把所有片段都评成强钩子。

## 选定后的全文检查

方案与比较交完的同一轮，主动请用户选择，并明确告知选后保留原稿全部信息、按情境融合全文。已有选择与原稿时直接交完整融合稿，按 [情境设计方法](情境设计方法.md) 的选后流程执行。

全文检查：开头、正文和结尾是否处于一致的交流关系；称呼、指代、时间与前因是否准确；文字本身是否体现对谁说、因何而说；所有原信息、数字、条件、例子、观点和情绪是否保留。方案轮不展示推进收尾的约束不限制此阶段交付全文。
