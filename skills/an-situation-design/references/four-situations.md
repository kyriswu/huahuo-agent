# 四方案配比、差异与人群比较

用户在情境设计对话里发来材料或文案时，方案阶段默认交付四个完整方案、各自匹配的开头与比较：方案 1、2 直接对镜头、对观众说；方案 3、4 与现场的人或事互动，由第三方记录。先使用当前认证用户已注入的 `positioningReport`，理解这份内容服务谁、提供什么价值；本轮明确指定且获准使用的定位材料可作本轮依据，没有定位仍依据本次材料设计，不强制建档。

## 先确定表达关系，再设计事件

| 组别 | 主要交流／行动对象与观众位置 | 拍摄关系 |
|---|---|---|
| 方案 1、2：直接对镜头、对观众说 | 你主动向观众讲述、倾诉、解释、演示或邀请其判断，观众是交流对象。 | 自拍、固定手机、他人掌镜均可；有人掌镜仍可能是直接对观众说。 |
| 方案 3、4：现场互动，由第三方记录 | 你主要与现场的人或事互动，观众通过记录观看事件。 | 由另一个人拍摄，可为在场朋友、同行者等；可知情、自然回应镜头，不默认偷拍或隐藏机位。 |

朋友记录你在饭桌上聊天，与同行者记录你处理现场问题，是同一大类下不同的事件，不拆成两个表达类型。归类综合主要对象、拍摄者、观众位置，不能只看是否有人拿手机或是否偶尔看镜头。两组不能把同一个情境换个机位后复制。

**时间是独立维度。** 刚发生、正在发生、即将发生都可成为开口或行动的原因。直接对镜可以事后分享、同步讲述或事前准备，不强制两案各占一个时间类型；第三方也可记录复现、创作演绎或准备过程，不要求故事在现实里已经发生，不逐项加假设声明；不把设计回写为用户档案事实或真实案例证明。不要把事后讲述当成必然没有情境，也不要把偷拍设为情境成立的条件。

## 在同一内容核心下拉开差别

两组内部分别探索多于两个候选，各选两个，使四案在固定“2＋2”下尽可能拉开差别；候选推演不必展示。不要找到四个勉强可区分的方案就停止。检查以下维度，但不要求每次套固定组合：

| 维度 | 真正改变的是什么 |
|---|---|
| 人物关系 | 对观众、自己、亲近的人、服务对象、陌生人或群体；关系会改变为何开口、怎样回应。 |
| 场内目的 | 要作出选择、完成任务、解决误会、照顾对方、解释发现、争取回应等。 |
| 核心行动 | 人物怎样推进事情；不能四条都只是“停下来给另一个人讲课”。 |
| 互动／阻力 | 来自自己、他人、环境或群体的什么具体作用；并非一定有敌意。 |
| 切入时刻 | 决定前、行动受阻时、结果显现后、等待回应中等，让观众产生不同问题。 |
| 观看关系 | 观众是参与者、被指导者、旁观者、见证者还是亲近的倾听者。 |
| 情绪与获得 | 理解、安心、好奇、代入、陪伴、实用判断等，必须由事件支撑。 |

资源允许时，满足配比后，每一对方案优先在“人物关系、场内目的、核心行动”中至少两项明显不同，并进一步拉开观看关系或情绪获得。逐对说明：观众进入的是哪两件不同的事，为什么观看感受也不同？这是筛选工具，不是凑差异数量；目标是明显悬殊，而非勉强不重复。去掉地点名和人物称呼后仍几乎相同，就重新设计。只有镜头、道具、台词或紧张程度不同不够。

特别留意组内表面换事、观看体验相同：两案都只是检查东西后对镜解释，即使分别叫“购买前”和“收拾时”，也可能过于接近。保留本组表达关系，改变人物目的、核心行动或观看获得；受严格条件限制时如实说明差异空间。四案全部直接对观众说或全部第三方记录，都不满足默认配比。

固定的只是两种表达关系各两个，不限定日常、冲突、课堂或事件时间。四个都应有明确目的、行动与关系；直接向观众讲述刚发生的事可以是行动，不要求额外配角或肢体动作。纯背景讲解需补清此刻为何开口，不能只靠标签凑情境。

## 差异受内容与资源约束

- 保留材料的核心意思、作者立场与情绪力度、已确认定位及用户明确的拍摄限制；不要为吸引另一类人偷换主题。
- 内部区分已具备资源与创作设想；默认对外只描述拍摄关系，不列最低配置、协拍缺口或可拍性结论。第三方记录两案可设计由朋友、同行者等拍摄，不把这些人写成用户已具备的资源。固定手机自拍不得冒充第三方。用户当轮明确全部方案都须单人可拍或只要一种表达关系时，以该明确范围覆盖默认配比。
- 角色身份与故事可以设计，包括人物职业、心理与对白；不能把虚构资质、客户或成功案例当作现实权威与效果证明。
- 本轮指定同一种关系或同一地点时，优先满足硬约束，再在剩余维度尽可能拉开；如差异空间有限，如实说明，不造假或强行加冲突。
- 内部判断原稿能否自然进入该关系，不让配角为听完整篇而无故等待；方案阶段不展示中段承接、推进与收尾设计；用户选定后，按主方法的“选定后全文情境化”直接交完整融合稿。

## 每一种都交到可用

方案说明统一用第二人称“你”指代使用者／创作者，例如“你把两本账摊在桌上”“你回头对老板说”，不默认写成“他／她”或用“人物／创作者”绕开称呼。四案及比较中的创作者指代都遵循此规则，第三方记录也不改变文字人称。具体台词按实际说话者自然使用“我、你、我们”等；配角仍按关系、姓名或相应人称称呼，不把台词里的“我”或配角的“他”机械替换为“你”。用户明确指定其他叙述人称时按当轮要求。

默认每种用一个紧凑段落或三个要点，以相近深度只写清：①情境和目的；②前因与开场（切入动作、可直接使用的匹配开头文案）；③交流与拍摄关系（主要对象、拍摄者、观众位置）。不默认输出“推进与收尾”“拍摄条件与事实边界”，也不将其并入三项、共享说明或附注。完整行动链、明确资源限制与证明性内容的依据留在内部检查；普通创作不逐项核实，也不写入本人长期档案。短材料无需扩写成长报告，只有用户明确要求对应细节时才展开。

不要把四套全文文案当作四个情境。方案阶段给出匹配的开头，保留用户原稿的内容核心；选定后直接融合全文，保留原稿全部信息。默认交付四案时，不能交一个详案加三个标题，再要求选中才补齐。

## 最后的比较必须写具体

| 必需项 | 写法 |
|---|---|
| 更可能吸引的人群 | 写具体处境、需求、认知阶段或观看动机，再解释情境中哪个动作、关系或问题能叫住他们。不能四个都写“对主题感兴趣的人”，也不要没有依据就编年龄和性别标签。 |
| 与定位的关系 | 已有定位时，说明主要服务核心人群、相邻人群，还是可能吸引偏离目标的围观者；受众可重叠，不为凑四个而强造互斥人群。没有定位时将判断标为基于材料的暂定分析。 |
| 优点 | 解释该情境如何帮助理解、共鸣、信任、持续观看或实际拍摄。避免无依据地承诺“更容易爆”。 |
| 缺点 | 写与这个方案直接相关的代价或局限，例如需要默契配角、表演要求、铺垫占时、讲解容量、误读可能或吸引错人；不要四项都只写“需要演技”或“拍摄困难”。 |

可以合并成“方案｜更可能吸引谁及原因｜优点｜缺点”的比较表，把定位适配放在人群栏。比较应当帮助用户选择，不打没有依据的流量分数或虚构转化比例。

四个讲完后可以依据具体方案的观看价值、定位与实际条件说明倾向，不预先把某种表达关系等同于更亲近、更专业或更真实。用户没有要求你选定时，不宣布某一种永久最优；推荐也不替代完整交付。

## 方案轮最后一步与选后续做

四案及比较之后，同轮必须主动请用户选编号，并说明选定后会按该情境统一开头与全文的称呼、指向和交流关系，不删减原信息，交付完整融合稿。只有观点而无原稿时，告知选后还需原稿；已给过的直接承接。明确只要方案或局部处理时遵从范围。

用户已选定且有原稿时，直接执行 [情境设计方法](情境设计方法.md) 的“选定后全文情境化”，不再询问是否合稿，不重新生成四案。方案三项格式只用于候选展示，不限制最终完整文案。
