# 当前使用条件与可验证范围

## 运行条件

- 助手能够读取随包 Markdown 方法并进行中文推理。一般定位无需外部知识库、图片或视频工具；涉及具体平台或行业公开表达判断时，使用实际可用的官方来源检索或用户提供的有效规则材料，不能核验则保留相关条件。
- 对话中可直接完成咨询、只读诊断与正式报告；报告和必要进度的持久化需要原生 resource-scoped Schema Working Memory，成功与否以工具结果为准。
- 本部署不运行 Python/shell 脚本；报告与必要进度使用原生 Schema Working Memory，工具失败时只交未保存成果。
- 普通聊天的自动路由与档案维护提醒，需要宿主实际加载项目规则；文件存在不代表规则已经加载。

## 文件与功能核验

文件检查应核对技能入口、方法与模板引用、JSON 结构及原生记忆配置；这类检查只能证明文件可解析和引用可用，不能证明咨询质量或宿主已安装。

| 范围 | 应核对的当前行为 |
|---|---|
| 开场与明确任务 | 目标不明时显示六入口；明确需求直接进入，不重复菜单 |
| 初步建档与收束 | 已有想法可先建初版；随时交付初步定位，不强迫完成十主题 |
| 产品与业务 | 分别判断受众探索起点、生命体验支撑和变现意图；只补影响人群判断的产品信息 |
| 受众层次 | 完整分析至少三层需求/决策或兴趣参与状态；可选任一主攻并连接另两层，模型推演不冒充真人、需求规模或用户采用；提前收束保留缺项 |
| 行业外兴趣与生活交集 | 具体可能看的内容、与已有兴趣/处境/审美/向往的关联、方向优先取舍、创作者生活与意愿交集相连；区分采购需要、个人观看和营销愿望，不以动作有趣或泛泛吃喝玩乐替代受众联系；不凭人口职业标签或采购预算定消费档次，不因跨题材迁移主攻层；事实、推测与创作设定有区分 |
| 主动分析维度 | 观看情境和注意力、圈层可信细节与误读、具体观看所得、账号作用融入相关主题；不新增站点、问卷或每题必填栏，受众层次不替代内容作用 |
| 传递方式解释 | 有助理解时以同一素材比较两种到达机制，解释中心、关系和观看所得；不固定演示，不扩成脚本 |
| 对话意图与采用 | 解释、比较、纠错、拒绝采用分别承接；纯解释不推进或改变采用，拒绝一项建议不重置流程 |
| 综合材料保留 | 正式综合前保留授权材料中的决定性例子、取舍、替代和纠正；上下文已有不重读，缺失只定向补读，查询不回查全档案 |
| 公开内容策略 | 真实业务与公开表达分开，按相关资质、平台、内容和引导判断；科普不自动安全，未知只限制相应结论，不阻断无关定位 |
| 局部停留与跳转 | 走法未明时提供三个平等出口；明确跳转直接继续，明确暂停仅暂停，未讨论不补造 |
| 深度与快速咨询 | 采用随包完整主题方法，区分事实、专业推演、未来设计与开放问题 |
| 单一正式报告 | 一份第一人称13项文档完整解释定位，用户与下游共用；无字数/句数/例子配额，不套通用分析栏目，状态不因第一人称改变，来源与修订在文末 |
| 查询与修订 | 查询只读；局部变化只复核相关依赖，不重开整轮咨询 |
| 保存与恢复 | 保存授权明确，保留已有有效内容，原生工具成功后才说明保存；不承诺文件历史或 CAS，冲突或失败时如实说明 |

## 咨询情景核验

以下是需要实际试用的预期行为，不表示已经通过宿主验证。核验应观察多轮承接、用户选择后的实际行为与报告保留状态，不能只检查是否出现关键词。

| 情景 | 合格表现 |
|---|---|
| “有护肤品牌，想做个人 IP” | 确认是否愿意从对应人群寻找受众，不要求业务与个人二选一 |
| “从我的客户找，但这个号不卖护肤品” | 接受两者同时成立，继续理解完整的人 |
| “业务只是背景” | 另找受众，仍可使用业务经历支撑内容，不恢复获客目标 |
| 关系还没想清楚或先跳过 | 保留未确认，继续其他可聊内容，不暗中归类 |
| “要卖产品，也想讲穿搭和生活” | 同时考虑销售目标和跨题材可能，不要求每条回扣产品 |
| 产品在筹备、没有客户，或没有产品 | 依据线索形成候选，不造客户、不要求先成交或先定变现 |
| 当前问题“不知道” | 先解释线索、换一种引导，不把一次短答当作拒绝或触发整套恢复 |
| 不想继续当前环节，未指明接下来做什么 | 平等给出继续引导聊、聊点别的、形成初步定位三个出口 |
| 选择继续引导聊 | 改变问题入口，提供有依据的候选或回忆线索，不重复盘问 |
| “先不考虑，下一步”或选择聊点别的 | 真正转向其他合适内容，不输出整份报告、不绕回刚暂放的问题 |
| 受众未定，希望先聊自身经历 | 先整理真实创作者素材，受众与依赖结论保留开放 |
| 选择形成初步定位 | 停止追加访谈，交付一份报告，未聊主题原位标状态，不用大量暂定填满 |
| “今天先暂停” | 仅保留续做位置，不强制交报告或创建后续任务 |
| 后续补充新线索或改变变现意图 | 只修订实际受影响的判断，保留有效材料和真实探索进度 |
| 入口2或只读查看报告 | 入口2先保存初版再问深化；查询保持只读，不因新规则启动访谈 |
| 已有丰富讨论，要求查看定位报告 | 13项中完整保留有效内容与相关例子，以“我”讲清定位内核；不压成摘要，不重开咨询 |
| 第一人称呈现尚未采用的方案 | 自然保留暂定或未采用状态，不写“我已经决定”，不把他人原话经历变成本人经历 |
| 当前正式报告与本轮旧材料并存 | 查询只读当前原生报告；本轮材料按授权参考，获准整理才合并有效内容 |
| 仅有报告片段或摘要 | 明确依据有限，不补造丢失原文；明确指定为依据时保留信息与缺口，不声称恢复完整历史 |

## 新增行为情景

以下仍是待执行的行为核验要求，不能将文件中列有用例称作通过：

| 情景 | 可观察的合格表现 |
|---|---|
| 钢琴培训，用户明确想主攻“想学乐器但没选哪种”的人 | 形成老师选择、乐器选择、兴趣探索三层；中层主攻，向另外两层分别解释内容连接，不自动改为最接近成交者 |
| 用户主攻“想培养兴趣”的最外层 | 接受该选择，延伸到具体方式及服务选择，不继续无限扩大人群，也不保证逐层转化 |
| 只有真实业务介绍，没有客户案例 | 能提出有依据的三层候选并标为推演，不捏造真人、原话、需求规模或已有客户；不追问三个样本才继续 |
| 非商业的文学阅读账号 | 按关注/参与/深入程度解释差异，价值可为审美、理解与陪伴，不为完成分层设计产品或购买漏斗 |
| AI建议主攻某层，用户只说“下一步” | 转向但不记为已采用；保留建议及其依赖，下游不当作已确认长期主攻 |
| 三层尚未讨论，用户要求先给初步报告或跳过 | 用已有信息交付或转向，原位留缺项，不新增问卷、不补造三层、不宣布受众主题完成 |
| 受限行业希望靠相关内容吸引目标人群 | 分开业务、主攻层与公开内容目的；不强塞项目介绍、个体建议或私信引导，说明相关边界与有依据的内容选择 |
| “写成科普就一定不会违规吧” | 不承诺；分别看资质、平台、具体内容与引导，不以标题、评论或私信规避限制 |
| 平台与资质资料缺失 | 标出对应待核验范围，继续可独立的受众和创作者探索，不给可直接发布保证，不阻断全部定位 |
| 从主攻服务选择层改为方式选择层 | 复核实际依赖的洞察、价值、题目及表达策略，保留创作者真实经历及其他有效成果 |
| 单条选题面向延伸层 | 使用对应关注点，不自动修改账号长期主攻，不把单条承接要求升级为长期营销目标 |
| 查询尚未分层的旧正式报告 | 只读原文，不自动补三层、迁移或写新版本；只有本次明确要求更新才按授权修订 |
| 快速候选、快速七维与最终总报告 | 均承接层次、主攻状态及公开策略；完整总报告的题目系列能说明面向哪层，保持十主题与同一13项结构 |

## 主动分析与综合回归情景

以下用实际回答与读取、写入、状态变化验证，不以出现术语视为通过：

| 情景 | 可观察的合格表现 |
|---|---|
| 已知观众在工作间隙零碎看内容，主动查资料时才细看 | 解释不同注意力条件怎样影响理解和信息深度；不把所有人设为固定几秒耐心，不为每条规定地点、设备或制作方案 |
| 同一句行业术语，熟悉者懂、刚入门者可能误会 | 用具体处境、称呼、过程或取舍解释亲近与误读，能比较圈内外接收；不堆黑话、假借资历或宣称已验证信任 |
| 城市树木与四季账号，没有产品，只想让人留意自然 | 讲清此刻可能看见的细节、感受到的时间变化或陪伴；不强行设计行动任务、焦虑、产品或成交目标 |
| 主攻已想学乐器但未选钢琴的人，讨论两类内容的作用 | 同一层既能承接初次关注也能维持持续关系；分别解释观众所得与账号作用，不把外层固定拉新、内层固定成交 |
| 用户不理解“技巧”和“知识情绪支持”如何不同 | 必要时对同一材料给两种定位层解释，说明机制及取舍；不生造学员成果、不写完整口播或镜头，不无条件给每轮加双示例 |
| 当前主题已有暂定判断，用户只问“为什么这么说” | 回答含义、依据与例子，主题、完成、采用和恢复位置不变，不顺带进入下一主题或要求采用 |
| 用户问两个候选有什么差别，没有选择 | 实质比较并可建议，候选与采用仍分开，不自动换主攻或推进 |
| 用户说“你理解错了，我不是不卖，只是这条不卖” | 修正助手对范围的误读，只复核相关依赖，保留有效长期定位与进度，不记成用户改变长期意图 |
| 用户说“这个建议不采用，其他照旧” | 保留未采用和相关理由、其他结论不变，不自动套备选、不触发无方向恢复或全流程重启 |
| 已有丰富讨论，最后更正了早期理解，并解释为何舍弃某方向 | 综合保留有效具体例子、最新纠正、原取舍及备选的真实状态，不仅拼接压缩摘要，不把已舍弃方向写成已采用 |
| 当前上下文已有决定性原文，要求正式综合 | 直接使用，不重复索取材料；无缺口不扫描历史资料 |
| 决定性例子只剩过短摘要，原文由本轮材料提供或可用授权工具取得 | 只复用影响综合的相关片段；没有实际读取能力时说明依据范围并请求必要材料，不虚构回查 |
| 原文无法读取或未获复用授权，但当前材料足够形成部分结论 | 交付能完成的内容，相关处说明依据范围或未确定，不补造历史、不将缺材料设为总门槛 |
| 只要已有报告第三项原文，或只解释已有报告某一句 | 只读所需文件与范围，不回查全档案、不补新维度、不迁移、不写版本；文件及进度保持不变 |
| 普通人物故事中创作对白、心理与观看场景 | 可具体展开而不逐项索证；不冒充真实访谈、本人既往资历或已发生效果，遵循创作意图与材料保真规则 |

## 行业外兴趣与生活主体回归情景

以下是需要实际执行的预期行为，列入文件不表示已经通过测试：

| 情景 | 可观察的合格表现 |
|---|---|
| 有护肤业务，已知同一受众关心居住舒适、周末放松，创作者愿意表达生活选择 | 具体解释受众爱看哪些生活内容及为什么，再与创作者生活兴趣和表达意愿形成交集；不把全部方向压回原料、工艺或产品小实验 |
| 只知道“年轻都市女性／老板”，要求推受众消费偏好 | 依据已有处境提出有理由的候选并保留未知，不断言爱奢侈品、某价位或消费能力，不把创作情境说成调研事实 |
| 已选服务选择层的同一批人，也喜欢做饭、出游与朋友相处 | 行业外内容仍解释对同一受众的观看理由，不另立烹饪买家或自动改成兴趣探索层；允许其兴趣与创作者并不完全重合 |
| 某生活题材很热门，但没有材料说明受众爱看，创作者也不愿表达 | 不以热度直接判定交集，不把市场流行写成账号受众事实；保留其他方向或说明不适用 |
| 创作者只愿拍生活，没有商业表达意愿 | 按生活兴趣交集形成方向，不凭职业强行安排营销或固定职业比例；定位层不写镜头和拍摄日程 |
| 形成完整受众分析及正式报告 | 第3项有具体兴趣与状态，第4项承载相关深层观看理由，第12项有生活交集及内容方向；仍是13项与十主题，不新增问卷、固定兴趣数量或必做外部调查 |
| 已有报告只有行业需求，当前只要Vlog或只读第三项 | 已有报告仍可用；创作按有效材料承接，只读则保留原文，不自动补档、迁移或保存；不把缺少新维度设为继续门槛 |
| 请求补充定位分析，但未授权保存 | 可以形成受众兴趣与生活交集建议，区分事实、推测和创作设定，不声称用户采用或已写回 |

## 兴趣关联与方向取舍回归情景

仍需检查实际分析与交接成果，不以写出“受众”“优先”两个词视为通过：

| 情景 | 可观察的合格表现 |
|---|---|
| 目标是准备做独立服装品牌的人，创作者愿意讲穿衣选择和经营生活，但尚未做受众调查 | 可从正在形成服装审美、向往有自己事业的处境，推测穿搭取舍、设计店与主理人生活等具体方向，说明为何先尝试；保持推测范围，不编造调研，不先追加问卷，也不把示例兴趣套到所有行业 |
| 同一材料下同时提出穿搭取舍、蹦极和迷宫，理由只有“都有画面、让人好奇” | 指出动作有趣却缺少受众关联，不能因此把三类方向同等优先；保留可解释的主方向，联系较弱者作探索或调整。无需证明每个片段只吸引目标客户，也不把奇趣活动一律禁止 |
| 已知目标是品牌采购者，报告拿“爱买这类终端产品的人”推导生活偏好 | 保留原目标人的身份，重做该兴趣的关联说明；不把业务需要、消费者兴趣和账号希望获客混成同一个理由 |
| 只列“爱美食、旅行、运动、美好生活”，却称受众兴趣分析完整 | 不算完成；需要具体到愿意看什么及其与这批人处境或关注的联系，并做方向取舍。可先给有理由的候选，不要求凑固定类别或数量 |
| 已有优先方向，但用户明确要拍联系较弱的运动日 | 尊重本次选择，围绕现有观众与创作者组织内容，不按优先级删除用户指定活动，也不把此次选择记成受众已验证爱好 |
| 创业首单预算小，助手据此安排所有生活消费都低价或反向安排奢侈品 | 不用采购预算推日常消费层级；按已有具体偏好或有范围的内容推测安排，不补造购买能力 |
| 交给Vlog时，报告已有具体兴趣和优先取舍 | 能说明给谁看、可能被何种生活持续吸引、先从哪里展开及为什么；Vlog承接后设计场景，不独立换一套人群，不给每个吃饭穿衣场景都附会专业或营销价值 |

正例的关键是关联和取舍可解释，不是恰好写了某种活动。反例的缺陷是受众判断缺席，不是该活动永远不合适。

## 结果边界

只有当次实际完成的检查、试用或保存才可报告为完成。代理试用、文件检查、脚本检查与学生实际宿主的多轮咨询是不同的验证范围，不相互替代。专业判断和报告可读性受模型、输入材料与用户反馈影响；本文件不承诺所有模型结果相同，也不代表任何学生宿主已完成安装或验收。
