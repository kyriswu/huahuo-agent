# 方法来源与索引

本包提供账号定位咨询、受众与创作者分析、定位报告及授权定位记忆维护方法。完整专业方法随包提供；运行适配见 [Mastra 原生运行与记忆协议](mastra-memory.md)；本包不携带原始文件哈希清单。

## 当前方法索引

| 能力 | 包内入口 | 使用范围 |
|---|---|---|
| 六入口、初步建档、提前收束与只读查询 | [开场分流](entry-flow.md) | 根据本轮需求进入，不以完整深化为交付初版的门槛 |
| 策略师角色、信息分层、答后分析、推进与修订 | [咨询方法](consultation.md) | 解释、比较、主张与综合由助手承担 |
| 十个深度主题、两个快速主题、无方向恢复 | [完整主题方法](positioning-subject-contracts.md) | 按当前主题使用完整判断维度与完成标准 |
| 产品与业务关系 | [咨询方法](consultation.md)、[完整主题方法](positioning-subject-contracts.md) | 分别判断受众探索起点、生命体验支撑和变现意图；按人群判断需要了解产品 |
| 受众层次与公开内容策略 | [专项方法](audience-and-public-strategy.md) | 至少三层、任一主攻与两层延伸；同一受众行业外兴趣、观看理由与创作者生活交集；区分业务与公开内容，核验相关资质、平台、内容和引导边界 |
| 当前环节的继续方式 | [咨询方法](consultation.md#当前环节的三种继续方式) | 可换聊法、换主题或形成初步定位；明确指令直接承接，暂放不等于完成 |
| 单一正式定位报告 | [定位报告协议](positioning-report-views.md)、[报告模板](../assets/定位报告模板.md) | 一份第一人称13项报告供用户阅读与下游共用，历史旧稿只按授权整理 |
| 当前主题、采用状态、后继、依赖与恢复点 | [进度与资料](continuity.md)、[会话模板](session-template.json) | 只记录真实处理进度，按授权保存原生 `positioningConsultation` |
| 档案维护和下游交接 | [主动维护](profile-updates.md)、[定位报告交接](positioning-handoff.md) | 区分持久事实、设计与待确认信息，按实际授权更新当前原生报告，保留无关有效内容 |

## 使用边界

本包的执行规则以 [SKILL.md](../SKILL.md) 与上述入口文件为准，来源记录用于追溯，不覆盖当前任务范围。主题方法决定专业分析覆盖，开场分流决定入口与交付，咨询方法决定产品关系与交叉探索，定位报告协议决定报告呈现与维护。

资料保存使用 Mastra 原生当前用户 Schema Working Memory，不运行本地保存脚本，不提供文件版本归档、输入绑定、后台监听或应用前端进度条。语言风格已作为独立技能接入 `languageStyleProfile`、`languageStyleLearning`；定位咨询不套用风格，独立明确请求按其方法衔接，定位与风格保存授权分别处理。主题方法自包含，不依赖未随包的课程卡；方法解释只能引用实际可读取的内容。运行条件与验证边界见 [validation.md](validation.md)。
