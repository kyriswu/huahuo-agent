# 道具设计｜使用说明

观众熟悉什么、怎样理解映射、为何关心这种呈现，可参考已有观看情境和期待所得；不新增受众问卷，不读取个人语言风格档案。

版本：1.4.1

这个技能帮助你把想说的内容变成观众看得见的道具构思，适合在拍短视频前选择道具。完整专业方法见 [道具设计方法](references/道具设计方法.md)，全部所需方法随本技能提供。个人IP或获客文案需要专项道具构思时，明确调用本技能，直接承接已有材料。

## 导入与使用

本技能已作为 Mastra 原生技能配置到 HuoX。登录当前测试 Studio 后选择 HuoX，说“用道具设计处理下面的文案”，再粘贴材料即可。方法由原生技能工具按需读取，部署包含本目录，无需业务负责人另装 ZIP 或其他技能。运行边界见 [Mastra 运行与资料协议](references/mastra-runtime.md)。

本技能结合你本次提供的材料、要求和道具方法，按 [受众资料协议](references/audience-context.md) 使用当前用户原生定位记忆中的相关受众信息。每案会考虑观众是否认识物品、能否看懂它与内容的关系、是否对这种呈现感兴趣。没有定位时按本轮受众与材料继续，只在关键缺口影响构思时必要补问，不重新访谈。

仍不读取或套用语言风格档案，也不在道具创作中维护或自动写回定位与风格。你不必先决定要用哪类道具。有本次受众、预算、场地、现成物品等限制，可以一并补充；没有拍摄条件说明时，优先设计容易取得、单人或少人能操作的道具。定位不代表你已经拥有相应道具或完成过准备。

## 可以输入什么

以下四类材料都可以，混合提供也可以。

| 输入类型 | 示例 |
| --- | --- |
| 一句观点 | 人与人的边界感，是给彼此留下自由。 |
| 一段文案 | 我以前总觉得衣柜越满选择越多，后来才发现，我每天穿的还是那几件…… |
| 一个知识点 | 有限的注意力在多项任务之间分配，会影响每项任务能得到的投入。 |
| 一个产品卖点 | 这件外套可以拆下内胆，方便根据天气调整穿法。 |

可以这样发：

> 请用“道具设计”为这个观点构思短视频道具：衣柜越满，不等于选择越轻松。我一个人在家拍，尽量用现成物品。

## 会得到什么

先用一句话概括内容的核心意思，再固定给出 **3＋3＋3 个方案，每个分别说明优点和缺点**。你本次明确要求其他数量或范围时，按本次要求调整。

| 类型 | 数量 | 帮你解决什么 |
| --- | --- | --- |
| 比喻型 | 3 个 | 用物品的形状、关系或变化，说明一个抽象意思，并解释对应关系。 |
| 载体型 | 3 个 | 借一件或一组物品的细节、用途、选择或故事经历，把内容讲具体。 |
| 准备型 | 3 个 | 把实际比较、记录、整理等准备工作变成可展示的物品。 |

每条都说明：**用什么、怎么用、为什么适合这段内容与目标受众、优点、缺点**。需要额外制作的，会写明条件；只有作为真实效果或案例证明使用时才要求实际记录。受众判断融入这些说明，不另附一份定位报告。

优点和缺点都针对每个具体方案分别说明：例如画面是否直观、材料是否容易取得、操作是否稳定、准备需要多久、是否依赖真实记录，以及哪里容易产生误解。你可以据此比较九个方案，默认不附加排名、首选、次选或两项推荐。

## 选择后怎样融合

九个方案给完的同一轮，会主动请你选择，并告知选定后将调整原文开头与相关段落、保留信息、交完整文案。直接回复方案编号即可，不必再说“帮我改稿”。只有观点而没有完整原稿时，选定后请补充需要融合的原文。

比喻型会在文案中说清物品与内容的对应关系；载体型让物品的具体细节带出观点；准备型说明准备内容与本条表达的关系。保留原稿信息、数字、条件、例子、观点与情绪力度，调整必要措辞和衔接，最后交完整融合稿。只要方案或只改局部时，可以直接说明。

## 使用时留意

- 先提供道具方案供选择；选定后直接将道具与内容的关系融入原稿，交完整文案，不自动制作完整分镜或出图。
- 准备型方案写“先记录一周”时，意思是需要你实际完成后再展示，并不表示你已经有这份记录。
- 普通物品故事、设定笔记和叙事痕迹可以创作；用作实测效果、真实案例或已完成投入的证明时，不能伪造记录和反馈。
- 比喻用来帮助理解，不能当作产品效果或科学结论的证据。

想看看完整输出，可以阅读同文件夹中的《示例.md》。

## 创作中的材料保真

本技能以作者意图与表达自主性为先。尊重用户的立场、情绪、判断和表达力度；除非用户要求求证或批判，不自动纠偏、降温、平衡、道德化或强行成长、和解。普通故事、人物、对白、心理、比喻和情境可以围绕表达目的创作，无需逐项求证或标注待验证。依据要求集中于效果承诺和作为真实证明使用的案例；不得伪造研究、名言出处或实测记录来为观点背书。用户明确要求只整理原稿、只改局部或保留指定内容时仍按范围执行，不能借创作换掉作者的观点。

材料保真首先检查有没有改掉你的观点、情绪和力度；不会因为“人性本恶”“世界没有好人”过于绝对就改成中性结论。事实依据检查只进入相关的效果承诺、真实证明案例和具名证据，不变成普通创作的统一门槛。
