# 语言风格｜HuoX 使用说明

本技能来自原包 `an-language-style` 1.5.15，已适配 Mastra 原生技能和当前用户 Resource Memory。完整专业学习与应用方法随包提供；不是只加一句“模仿我的风格”，不训练模型权重。

## 怎样开始

在测试 Studio 登录后选择 HuoX，直接说本轮目标并提供材料，例如：

- “这是我的定位和自己写的口播，请建立我的语言风格档案。”
- “这是你原来的稿和我亲手改后的版本，请校准表达偏好并更新适用规则。”
- “以后写口播，解释句少用反问、直接陈述原意。这是长期要求，记到风格里。”
- “这篇是别人的文章，只参考我指定的表达特点，不要当作我的样文。”
- “按我的风格改这段，只改前两句，不学习、不保存本篇。”
- “展示当前有效表达偏好和依据；这条不适合我，停用它。”

普通的“帮我改这篇”只处理本次文本，不自动学习。AI 草稿不会自动成为本人样文，明确认领其中一句也不认领全文。明确学习后可在授权范围连续接收材料，不每次询问是否记住。只有定位或一条可靠偏好也能开始，未知部分保持未知，不先填人物问卷。

## 会保留什么

先理解有来源的生活经验、知识熟悉度、交流对象与场景，再用本人真实样文、口述、改稿和明确要求校准。语言世界区分已知背景、暂定理解与未来目标，真实表达优先；不按城市、职业或学历规定口吻，读懂或引用某词不等于本人平时会主动说。

有效偏好只涉及少量有依据的措辞、明确避用与局部句法，不从题材词频建立必用词、通用 AI 禁词表或固定替换。“机制”“飞轮”等不是所有人的禁词，任务确需的专业概念、名称与引文保持准确。样文里的主题、观点、故事、因果和固定结论不会自动进入新稿，本轮明确授权复用内容时再按实际用途处理。

资料分为两个同级原生记忆键：

- `languageStyleProfile`：当前写作依据，包含简短语言世界、有效本人习惯／目标偏好、场景例外和来源索引。
- `languageStyleLearning`：完整获准原文、改前稿、来源类别、lineage、认领依据、候选、停用／替代、证据对照、学习记录与未决冲突。

完整原文不会用摘要冒充。两个键都会被框架加入上下文，长样文会增加后续每轮输入；分开存放区分用途，不代表按需检索或物理隔离。普通写作只使用相关有效 Profile，具体校准才使用必要 Learning 片段。当前没有独立源库或文件读取工具，路径和附件名不能当成已经读取的正文。

同一认证用户在新聊天可继续使用已有资料；另一用户的 Resource 独立。当前没有按账号／项目分组，确有多对象歧义时只澄清必要范围，不混合不同人的资料。个人资料不写入技能包。

## 本轮应用与长期维护

本篇语气要求只用于本篇；来源入库也不意味着规则立即生效。有效、候选、停用、被替代分别保存状态与依据，同稿变体沿用同一 lineage，不当作多个独立样本。

确有长期变化且没有既有授权时，先完成本轮成果，再展示“当前内容或缺项 → 拟更新内容与范围”，只问一次是否保存。明确长期要求、确认具体提案或已有相应连续学习授权直接执行，不重复确认。只同意部分就只改该部分；拒绝或暂缓无新变化不反复追问。

获准保存使用原生 `updateWorkingMemory`。数组整体替换时保留已有有效项，不把一次更新变成清空旧来源或偏好；工具成功后才说明实际保存范围。失败或未调用时提供可复制稿并明确未保存，不生成虚构版本、路径、哈希和回读回执。详见 [保存协议](references/storage.md) 和 [运行协议](references/mastra-runtime.md)。

## 与其他技能怎样配合

情境设计可按其角色与台词范围使用相关有效 Profile；方案说明与比较不套口头禅。独立开头处理、道具设计和内容升华仍不使用或维护个人风格，不因为记忆已注入而经摘要间接引入；本轮明确的语气与修改范围正常执行。另行明确的独立风格任务只改所指定部分，不重跑其他技能。

诊断、定位报告、方法解释和专业分析不默认模仿发布文案口吻。风格调整保留原意、信息、数字、引文、人物关系、逻辑方向、结构、情绪与表达力度，不把强烈判断改成客观平衡，不把犹豫改成断言，不偷带样文内容。普通故事与对白可服务创作；效果承诺、真实证明案例和具名研究不得伪造。

定位仍独立保存在 `positioningReport`。获准复用的定位仅作为相应背景，未来目标不写成现有习惯，报告措辞不当作本人表达证据。查询或修改定位遵循 [定位报告协议](references/positioning-report-views.md)，确认风格不自动授权定位写入，普通使用定位也不附送报告。完整 IP、获客、Vlog 等流程以实际已注册能力为准，本技能不代表已接入它们。

## 明确的适配边界

原包 Python 管理来源文件、SHA去重、证据分组、文件锁、预期指纹、手改快照、版本与回滚；这些没有一比一迁移。本版保留业务学习资料和当前风格 Schema，但没有不可变历史、CAS 或指定旧版本恢复。学习记录可以保留旧条目和依据，不是受存储层保护的历史日志。用户提供实际旧资料并明确授权时可修订当前值，不能凭摘要声称恢复了未保存的版本。

原生工具的结构校验不证明来源真实、授权成立或表达质量；HTTP／程序直接写入须由调用方显式校验项目 Schema。模型方法、静态检查、模拟链路、真实作者认可分别验收，不伪造相似度或通过率。当前值不会作为后台任务自动学习新聊天，也不承诺跨平台同步。
