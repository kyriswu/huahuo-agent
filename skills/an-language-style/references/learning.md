# 从生活与表达建立语言世界

## 材料及范围

沿用当前作者、交流对象、材料身份和已授权范围，不新增人物问卷。本人未提供的经历或知识背景保持未知；只有定位或样文也能开始，只下材料能够支持的结论。用户明确学习后可持续接收材料；普通改稿和讨论不自动授权长期保存。

| 材料 | 记录类别 | 能支持的判断 |
| --- | --- | --- |
| 本人明确认领的样文 | author | 该场景真实使用的词句；不能把题材词频当作风格 |
| 本人自然口述及可靠转写 | oral | 自然措辞、连接和拆句；去除转写错误，不照搬无意义噪声 |
| 本人亲手修改或明确确认的改稿 | correction | 同一意思下接受与拒绝的说法；先区分改事实、改观点与改表达 |
| 用户提供的定位、自述或经历 | 按实际来源记 author / oral / unknown，并在 source-note 说明用途为背景 | 语言世界的背景线索；报告中的推演、目标与事实分开，不证明其中措辞是本人用语 |
| 喜欢的他人文章 | external | 仅学习明确指定的特点，不证明本人已经这样表达 |
| 明确的长期表达要求 | preference | 按指定范围生效的目标偏好，保留原话 |
| 来源不明的材料 | unknown | 来源与候选观察，不认定作者、事实或本人习惯 |
| 明确认领的 AI 表达 | adopted-ai | 按认领范围作为目标表达参考，不冒充本人历史习惯 |

“这稿能用”不等于认领为学习样本；认可某句也不等于认可全文。未知来源可在已授权学习中记录并继续，不为补齐身份阻塞任务。第三方、采访对象、引用者、叙述者与用户本人要分开。同一原稿的反复修改使用同一 lineage，不能算作多个独立样本。

## 理解语言世界

从已提供或授权复用的资料中，只取会影响文字选择的生活经验、知识与概念熟悉度、日常交流对象和场景。没有定位不强制补做定位；来源指向其他文件不扩张读取权限。

区分已知背景、暂定解释和希望采用的表达目标。城市、职业、学历各只是线索，不给文化层次打分，不从身份推导固定词表或口吻。定位中的理想人设、未来身份、目标腔调不当作当前生活与已观察习惯。允许有依据的合理想象帮助在准确表达间暂时选择；无来源的人生事实不编造，暂定解释不升级为必须执行的规则，本人真实选择优先。

理解词汇与主动词汇分开：读过、听懂、引用过一个概念，不代表本人会自然用它。能理解专业词却在公众口播选择日常说法是正常场景差异；不能仅因表达日常就推断知识不足。新材料与推测冲突时修正推测，不把真实表达硬改成身份刻板印象。

语言世界保持简短，无依据的维度可省略。熟悉某类生活或知识不要求每篇都谈它，不从背景推导主题、观点、案例、解释框架或结论。

### 背景、愿望与表达证据的区别

例如定位写“长期做服装”，可以帮助理解哪些概念可能熟悉，但不能据此认定本人常说某个术语；定位第11项写“希望被记住为讲得明白的人”，只是表达方向，不证明已有口头禅。本人多次独立改稿把抽象词改成具体动作，才可按来源和适用场景形成措辞观察；明确长期偏好按其真实范围处理。普通写作应用已有风格档案，不为这项校准重新全面读取定位。

## 只提炼能落实到文字的选择

优先观察：明确长期要求、本人改稿选择、独立样文中反复出现且范围清楚的表达。只提炼措辞偏好、明确避用表达、局部句法（连接、转折、拆句、省略等）。口语、真诚、有温度等评价只有能落实到具体选择时才保留；不凑数量，不建立固定开头、论证套路、宏观节奏或升华模板。

每条候选先核对：是否有表达依据；能否在保持原意时执行；适用场景是否清楚；是否暗中规定了主题、立场、因果、文章结构或结论。批评对象、常讲的故事、价值主张、标志性比喻和固定归因不提炼为通用风格，亦不自动转存定位。

改稿按“原表达 → 本人表达 → 改变了什么 → 证据与适用范围”记录。一次缩句可能只是修正歧义或删掉冗余，先保留具体观察，不自动永久化。事实、内容及确定性修正留在该次反馈，不能伪装成措辞偏好。

例如，本人把“先理解背后的运行机制”改成“先弄明白它是怎么运转的”，可观察到该句用具体动作表达过程；只有明确长期要求或独立表达支持时，才提炼相应场景的偏好。例子不预填成学生规则，也不把“机制”全局替换成“办法”。词未出现不是避用证据，题材词频不是必用依据，“机制”“飞轮”等也不是所有人的禁词。

## 记录与生效

按 [规则模板](../assets/templates/rule.md) 记录少量具体偏好，来源与短对照留在学习记录。写作档案使用 [档案模板](../assets/templates/profile.md)，只载相关语言世界、有效本人习惯、有效目标偏好、场景例外和来源索引。原始材料、候选、停用与替代分析不混入默认写作正文。当前写作档案可保留确需记录的词、短语或用词选择对，不粘贴样文整句、故事和改稿证据对照；完整例句及分析留在学习记录，按来源索引校准。

- **有效**：明确长期要求，或在独立材料中反复出现、范围清楚且无未解决重大反例的表达选择。
- **候选**：单次观察、尚未明确采用的外部参考、范围不清或证据不足；留学习记录，不约束写作。
- **停用 / 被替代**：保留原因、依据和替代关系，不继续应用。

背景说明另标已知/暂定理解，不把背景事实当作语言偏好。没有机械的样本数量阈值，不生成相似度分数。已明确的偏好可直接按范围生效；其他观察不因“少提炼”而全部被禁用，也不因重复出现同一主题而升级。

## 冲突与已有资料

先判断文体、对象与场景差异，只在有实际需要时保留例外，不为每种身份创建模式。当前明确要求优先，既有有效规则不能被最新样文一概覆盖。作者手改档案是最新反馈；核对范围并保留原文本，不从历史反向覆盖。

读取混合档案时按用途筛选，标为有效的主题主张、永久立场或固定结论也不作为语言约束。不自动搬移或删除；获准维护后，将获准整理的原条目、观察、主题内容和状态说明保留在学习材料中，保留其原意和出处，不改写定位或扩大整理范围。原生记忆保存当前 JSON，不提供不可变快照；不能可靠保留获准范围以外材料时先交具体整理稿，不声称已经完成历史归档。局部维护不要求整理整份旧档。

## 保存与交付

按 [保存协议](storage.md) 将获准来源、有效当前档案与必要学习记录写入当前用户 Resource Memory；原生工具成功后报告新增或修正的具体条目和范围，不虚构版本、路径或回读回执。没有新增有效偏好时可以在授权学习范围内如实记录观察；不假称学会了完整风格。普通任务先完成当前成果，有实质长期变化再按 [主动维护协议](profile-updates.md) 提议，已有学习或保存授权不重复确认。
