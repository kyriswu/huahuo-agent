# 创作技能共用语言风格

先读 [Mastra 运行与资源记忆协议](mastra-runtime.md)。本文保留原专业表达边界，将原文件接口映射到当前用户 `languageStyleProfile` 与 `languageStyleLearning`；不假称存在文件或额外来源检索工具。

## 当前输入与作用范围

仅用于本轮允许参考语言风格的任务。独立开头处理、道具设计、内容升华和 Vlog设计不因输出含文字、交付复核或维护提醒而读取风格；另行明确的独立风格任务按其范围处理。

默认依据为框架本次实际注入的当前用户 `languageStyleProfile`。本轮明确提供且授权使用的风格 Markdown 文字可直接只读使用，不强制转换格式；只给路径或附件名不能当作已读正文。身份归属由服务端确定，不扫描目录、猜测其他技能或选择其他用户 Resource。

面向发布的文案起稿前，读取档案中与本次对象、文体和场景相关的简短语言世界、有效措辞偏好、明确避用表达和局部句法。语言世界只提供有来源的生活、知识和交流背景；已知、暂定理解、目标分开，知道或引用过一个词不等于会主动用。背景可柔性帮助在准确说法间选择，不能从城市、职业、学历推定文化层次、知识不足或固定口吻；本人真实表达和明确要求优先。没有必要信息就缩小作用范围，不凑规则、不启动画像问卷。

当前写作档案可保留确需记录的词、短语或用词选择对，不粘贴样文整句、故事和改稿证据对照；完整例句及分析留在学习记录，按来源索引校准。

不默认使用 `languageStyleLearning` 中的原样文、候选、停用分析或旧学习记录，不为应用风格重新全面读取定位或建立语言世界；即使两个键都已注入，也只按用途使用当前相关 Profile。原任务本来获准且确需读取定位时仍按其方法执行。只有明确的局部校准问题无法由档案判断时，才按真实来源索引使用实际可见且获准的必要片段；当前没有独立资料检索工具，缺失材料仅必要补问，不假称回查。已经在对话中的样文同样受用途边界约束。

## 怎样应用

本项目已接入的独立情境设计按角色与台词范围使用相关有效风格；独立开头处理、道具设计、内容升华不使用个人风格档案，包括上下文已有内容与其他技能的风格摘要。本轮明确要求的语气和范围正常执行。原包IP、获客等完整流程以实际注册能力为准，不能凭本协议声称已接入；其原子分析不以风格删信息、正文自然起始文字按授权应用有效风格等专业边界仅在实际对应任务存在时适用。已确认的独立开头只在获准修改范围内调整，仍保持构思法、精准词语和正文兑现。风格从起稿自然应用，交付前只做必要局部核对，不新增站点、批准步骤或固定整稿改写。诊断、定位报告、专业分析和方法说明不默认套发布文案口头禅。

风格只调整表达选择。选题、观点、事实、案例、因果、结构与结论由本轮内容任务及专业方法决定；不得从语言世界或样文补入身份故事、熟悉主题、商业归因、固定结论或升华。用户明确指定样文同时作为内容依据时，在指定范围正常使用。已经确认的立场也不因写在风格档案中就自动成为每篇观点。

另行明确的独立风格修改若只涉及开头、标题或某段，限定到该范围，保留原意、情绪与表达力度、信息、数字、引文、人物关系和既定结构；不把作者的强烈观点改成客观平衡，也不擅自强化原本犹豫的判断。普通创作中的故事、对白和设定由内容任务决定，不逐项核验；效果承诺、作为真实证明的案例及引用依据不得伪造。风格不覆盖十九法、独立开头十六法每法三案、营销必要行动引导等专业约束；不得把内容修正冒称语言调整。

不设置通用 AI 禁词表，不按题材词频强塞常用词，也不因样文没出现就禁用新词。明确避用偏好按语境处理，不机械一词换一词；必要术语、专有名称、直接引文和本轮明确讨论的概念保持准确。已经自然且准确的表达保留，语义不明时保留准确原句或给必要局部选项，不牺牲原意以追求口语。

## 混合档案与核对

档案含原文、候选、停用条目或主题主张时，只读筛选相关表达依据；标成“有效”的固定主题、立场、归因或结论也不作风格规则。未经维护授权不删除、搬移或重写条目，不改定位，不把自动整理设为开工条件。获准维护只处理实际范围，将原条目、依据和必要状态留在 Learning；当前没有完整不可变快照，不冒称已经备份。

交付前以本次实际注入资料、适用规则和用户最新更正核对，仅复核受影响的表达。同名文件或旧聊天不能代替当前值，用户手改的实际可见文本是最新反馈，保留原文，不静默用旧稿盖回。不生成不存在的路径、哈希、实时更新或并发校验回执。

交付前检查用词是否符合本人有效偏好、原意是否保持，以及观点与结论是否服务本轮作者意图、案例是否按本轮内容任务处理；不能只扫描几个关键词代表通过。档案不存在、只有空模板或无法读取时正常完成现有任务，不强制建档、不假称像本人；明确要求严格匹配但依据不足时说明实际范围，只补问必要材料。

## 谁负责维护

普通创作只读应用，新稿不自动成为样文。按 [主动维护定位与风格](profile-updates.md) 检查实质差异，先完成当前成果，再提出具体更新及范围；本篇要求只用于本篇，拒绝或暂缓无新变化不再追问。

明确长期要求、确认具体提案或已有连续学习授权时，按范围维护，不让用户再次手动调用或重复确认。样文学习及语言世界校准衔接已接入的 `an-language-style` 完整方法；获准的局部目标偏好可直接按 [保存协议](storage.md) 更新，不凭背景猜测建立稳定习惯。来源、范围、确认依据、候选／停用／替代状态与学习记录按真实材料保留；原生工具成功后才报告已保存及范围，不输出虚构版本、路径、历史快照或回读回执。不能保存时交付待保存稿。认可一句话不等于认领整篇 AI 稿。未确认的维护不阻塞独立创作。

个人档案只属于当前认证用户；没有按账号／项目分组和跨平台自动同步。归属歧义影响当前使用或保存时仅澄清必要对象，不跨用户共享、不混合不同人的风格。
