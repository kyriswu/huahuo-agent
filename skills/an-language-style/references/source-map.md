# 语言风格｜来源与 Mastra 适配范围

来源：用户提供技能包中的 `an-language-style`，原方法版本 1.5.15。方法以有来源的语言世界、少量措辞提炼与真实反馈校准为依据；本项目没有把风格简化为主题词表、口头禅集合或一句通用模仿提示。

## 保留的专业方法

- [学习与校准](learning.md)：保留七类来源、同稿 lineage、背景／目标／表达证据区别、理解词汇与主动用语、少量措辞／避用／局部句法、有效／候选／停用／替代、场景差异和原意保真。材料、语言世界、提炼、记录生效的核心专业正文原样保留；仅混合档案保存与最后交付段适配实际宿主。
- [应用风格](application.md)：保留内容职责、词句选择、必要术语、局部检查、作者立场和表达力度等专业正文；仅资料输入、来源回查、当前值变化与保存结果表述按原生能力调整。
- [共用档案交接](language-style-handoff.md)：保留只调表达、不搬入内容、不默认回读样文、相关场景应用和独立技能排除规则；文件接口换为实际 Profile／Learning，未注册完整流程不冒充已接入。
- [档案模板](../assets/templates/profile.md)、[规则模板](../assets/templates/rule.md)、[变更模板](../assets/templates/changes.md)：保留专业栏目、依据与状态、短对照和反例要求，旧文件路径／版本指针改为真实逻辑来源和学习记录，原生工具结果不冒充文件回读。
- [主动维护](profile-updates.md) 与 [定位报告协议](positioning-report-views.md)：保留具体差异、范围授权、不重复确认、一般赞同不长期化、风格与定位分开、13项同一正式定位等业务约定，按现有 Resource Memory 对齐保存。

## 当前字段与工具

新增 [Mastra 运行与资源记忆协议](mastra-runtime.md)。当前写作依据为 `languageStyleProfile`，完整获准来源与学习分析为 `languageStyleLearning`，获准变化由原生 `updateWorkingMemory` 保存；不是项目文件、额外源库或自定义工具。定位保持独立 `positioningReport`；未获授权、没有实际变化或与本次维护无关的记忆键不改动。

这两个风格键会被原生记忆整体加入上下文，用途分层不代表物理隔离或延迟检索。完整 `originalText` 与 correction 的 `beforeText` 保留获准原文，不悄悄换成摘要；长样文会增加后续每轮上下文。普通写作按指令只用相关有效 Profile，具体校准再使用必要 Learning 材料。

学习来源与状态保存不等于已掌握本人习惯。模型工具按 Schema 校验相应结构，HTTP／程序调用方需先自行校验项目 Schema；没有结构校验能证明材料归属、采用与授权真实。专业指令、静态完整性、模拟模型接入与真实作者认可分别报告，不伪造效果和相似度。

## 没有等价移植的脚本能力

原 `scripts/style_store.py` 仅负责文件保存，没有定位或风格推理。本版不包含、不运行该脚本，也未迁移它的字节 SHA256 自动去重、本人证据分组计数、独占文件锁、预期指纹 CAS、手改快照、不可变版本、文件事务回读与指定版本回滚。`learningRecords` 承接实际修订依据和旧条目，不是受保护的历史审计库。

原按项目／账号文件入口改为当前用户一组 Resource 资料，没有按账号／项目分组或旧文件自动导入。没有文件读取与独立历史检索工具，路径或聊天摘要不能冒充已读原文；当前明确旧材料可在授权范围作为当前修订依据，不声称恢复了不存在的快照。原生字段合并不等于同规则／数组的版本冲突检测。

## 宿主材料调整

`SKILL.md` 增加必读原生协议并保留学习／应用／维护入口；[使用说明](../使用说明.md) 改为 HuoX／Studio 实际用法。[原全项目规则资产](../assets/project-rules.md) 改为当前已接入技能的语言风格职责参考，不加载旧 WorkBuddy 全项目路由、未接入 IP／营销／Vlog 流程或后台文件保存要求。完整语言风格专业依据仍在本包 references 与模板内，不依赖该旧项目规则才能运行。

未带入原宿主 `agents/openai.yaml`、`_user_meta.json`、系统杂项和旧 `source-map.json` 指纹清单；它们不是必需第三方服务配置，原哈希也不能证明适配文件。当前不新增模型供应商、Python 运行时、文件工具或外部 MCP。方法只用项目模型、原生技能与记忆能力，不训练权重、不后台监听或跨平台自动同步。

本文件是来源和迁移差异清单，不代表真实模型效果已经验收。现行核验要求见 [验证范围](validation.md)。
