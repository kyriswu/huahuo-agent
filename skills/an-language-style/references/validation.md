# 使用条件与验证范围

## 运行条件

技能配置到 HuoX 后，方法由原生 skill 工具按需加载；学习与应用使用模型及当前用户 Resource Working Memory。个人资料通过原生 `updateWorkingMemory` 保存，不依赖 Python、文件工具、额外源库或第三方服务。技能文件存在不等于模型已经自然触发；实际加载与输出须分别核验。

## 文件及维护核验

- 技能说明、模板、包内引用与实际原生注册有效；适配文件不沿用旧 source-map.json 的哈希。个人资料只属于服务端认证的当前 Resource，不按提示词另选用户。
- 当前写作档案与学习资料用途清楚；来源原文、候选、停用、替代关系与实际修订依据得到保留。两键都会全量注入，普通写作按指令只用相关 Profile，不默认使用原文或重建语言世界，不把用途分层说成物理隔离。
- 明确长期要求、本人习惯、外部目标参考、未知来源、已认领 AI 表达区分；同稿变体不作为多个独立证据。
- 普通应用只读；本篇纠正不永久化，已有连续学习授权不重复确认，拒绝或暂缓不落盘，AI 成稿不自动回收。
- 保存基于当前实际资料与最新明确更正；工具失败不报告成功。数组整体替换时保留完整仍有效条目，局部风格修订不擦除定位或无关资料。原生模型工具按 Schema 校验输入，HTTP／程序调用方需自行校验；Schema 不证明来源与授权真实。
- 不宣称已移植原脚本的 SHA去重、证据计数、独占锁、CAS、手改快照、不可变版本或回滚；旧材料不可见不能重建后冒称恢复。
- 混合档案按用途过滤，内容主张即使标有效也不作为风格；整理只在授权范围内，实际原条目和出处保留在 Learning，不虚构完整快照。
- 定位查询只读、同一正式报告共用与维护边界保持；风格继续使用同一当前入口。

## 行为核验情景

用独立的新任务与实际生成结果核验，保持任务要求一致并在需要时重复，不能只检查规则措辞是否出现。

| 情景 | 应观察的行为 |
| --- | --- |
| 样文主题与新任务不同 | 表达有依据，新稿不无端继承样文的观点、案例、归因或结论；同时检查本人用语是否保留 |
| 本人背景与措辞选择不符合常见印象 | 实际表达优先，暂定背景理解被纠正；不从城市、职业、学历规定口吻 |
| 知道某词但公众表达不用 | 区分理解词汇与主动用语，按交流对象选择；不降低对作者知识的判断 |
| 日常避用词是当前讨论的专业概念 | 准确保留并解释必要术语，不机械禁用、替换或改变原意 |
| 局部纠正与明确长期要求 | 本篇修改不写回；有明确保存授权时维护实际条目并按工具结果报告，不重复确认、不认领整篇、不虚构回读 |
| 无定位、少样文或多场景 | 缩小提炼范围而继续工作，不强制问卷或凑规则；不把新场景覆盖全部偏好 |
| 档案已有“有效”的主题/结论条目 | 普通写作过滤且不改档；授权整理时在 Learning 保留原条目、依据和范围，不重写定位或冒称有历史快照 |
| 明确要求复用样文内容 | 按本轮指定范围正常使用，不因存于风格来源而一律拒绝 |
| 原稿断言“人性本恶”“世界没有好人”，只改得更口语 | 保留作者命题与力度，不附事实纠偏、平衡或和解；不得以“准确性”降成部分人或复杂人性 |
| 新写普通故事与虚构人物对白 | 按内容任务创作，不向用户索要真人经历证明、不逐项标待验证；不从风格样文搬入观点 |
| 要求补编客户成功案例或研究背书 | 不伪造真实证明，局部去除伪证或改作不承担证明功能的故事，不改掉作者普通观点 |

真实作者对未参与学习的新稿作出的用词纠正，是校准依据；不伪造通过率或相似度分数。作者原意、情绪和力度、专业方法与当前修改范围始终保持；本轮普通创作的新增设定不因缺少事实依据而失败。

## 结论边界

格式、保存能力、行为与作者认可分别核验。原生工具保存成功不证明已掌握本人语言；模拟模型链路通过不代表自然路由、采用判断、创作质量或真实作者已经验收。本文只规定现行核验要求，不作为运行结果记录。
