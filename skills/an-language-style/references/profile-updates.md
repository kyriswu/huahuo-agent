# 主动维护定位与语言风格｜Mastra

先遵循 [运行与资源记忆协议](mastra-runtime.md)。本协议维护当前认证用户的定位与风格资料，不是后台监听器，不扫描目录。开头处理、道具设计和内容升华仍只在各自范围取用受众，不因共用协议获得风格使用或档案维护职责；另行明确要求维护时作为独立任务处理。

长期档案的认领和保存不代替创作。作者的立场、情绪与绝对化表达不必被纠正或证明客观正确才可展开；普通人物、对白、故事和未来场景可服务表达，但不自动成为已发生履历、长期偏好或真实效果案例。只有实际的新事实、明确纠正和长期选择才形成维护候选。效果承诺与作为真实证明的案例仍需依据。

## 发现实际变化，先完成本轮成果

先区分解释、方案比较、事实纠错、拒绝未采用建议、撤回旧选择与长期表达要求。没有新事实或新选择时停留在解释，不改变采用状态、咨询进度或记忆。对助手误读的纠正不能记成用户改口；拒绝某建议不自动采用其备选。

涉及受众、需求、价值、方向、差异化、人设、系列或披露边界时，按实际影响检查定位；涉及具体措辞、避用表达、局部句法、改稿选择或会影响用语的真实生活／知识／交流背景时，检查风格。普通应用不为此全面重读定位、重建画像或索要问卷。事实、内容与确定性修正不能伪装成语言偏好。

比较对象是本次实际注入的 `positioningReport`、`languageStyleProfile` 与必要 `languageStyleLearning`，不是假定存在的文件。普通应用只使用本轮获准 Profile；发现真实的具体校准问题才取实际必要 Learning 片段，不因全量注入扩展为学习。缺失或不可见资料说明范围，不能当空白覆盖。

先完成当前阶段成果。有实际长期变化且尚无保存授权时，再用一小段说明“当前已存内容或缺项 → 拟修改内容、适用范围”，只提出一次具体保存建议。已有授权则直接在范围内保存，不把提醒变成重复审批。无变化、只是解释、他人案例或一篇临时创作不制造更新。

例如：“现有口播目标偏好是解释句多用反问，你这次明确希望直接陈述原意。要把它改为以后解释句的长期偏好吗？”若用户已说“以后都这样，记到档案”，直接按该范围执行。例子不预填为用户规则。

## 确认范围与提醒次数

- 明确建档、学习、连续学习、长期要求、确认刚展示的具体提案或已有适用保存授权，可以直接执行；不让用户再选技能或重复确认相同范围。
- 一般赞同、仅要求解释／比较、采用一篇稿、一次临时语气和本篇修改不自动授权写入。紧接具体保存提问的“可以”可承接该提案，不能扩大为持续保存或认领整篇 AI 稿。
- 拒绝、暂缓、只改本篇或未回应时，不写当前档案、来源、候选或学习记录；同一差异无新变化不换句话重复追问，也不阻塞独立创作。
- 定位与风格分别说明改动、依据和保存范围。允许只批准一类或某些条目，确认一种不推定另一种获准；初次建档不自动延伸为所有未来任务的持续学习。
- 目标要求不冒称已观察到的本人习惯；明确认领一句 AI 表达只作为该范围的目标参考，不认领全文。未来身份和背景推测不升格为已发生事实或有效规则。

## 确认后的语言风格维护

1. 按 [学习与校准](learning.md) 区分来源、用途与同源组。完整原话／原文写入 `languageStyleLearning.sources[].originalText`，改稿前文按 correction 保存 `beforeText`，adopted-ai 保留实际认领依据 `adoptionNote`。仅背景用途在 `sourceNote` 说明；报告措辞不当作本人表达证据。
2. 以本次实际资料和明确更正核对旧条目，保留无关有效偏好、候选、停用、反例、未决冲突及其原依据。同稿变体沿用 lineage，不编造多个独立证据。只整理获准的混合条目，把原文与状态说明保留在 Learning，不自动转存定位，也不要求整理整份旧档。
3. 有效的措辞／避用／局部句法放入 `languageStyleProfile.activePreferences`，背景按 languageWorld 的已知／暂定／目标分别承接，必要差异放 scenarioDifferences；候选、停用、被替代及原因放 Learning.observations。变更记录保留授权依据、sourceIds、受影响规则、前后内容、适用范围和仍需保留的线索，不把它们说成不可变历史日志。
4. 按 [保存协议](storage.md) 调用原生 `updateWorkingMemory`，只提交获准变化。数组整体替换时带回完整旧项；相互引用的 Profile 与 Learning 变化尽量同次提交，不用空模板覆盖，不改无关定位键。真实冲突影响修改时澄清具体差异，不虚构预期版本 CAS、手改快照或实时变化检测。
5. 工具成功后才简述实际修改条目和范围，说明已保存到当前用户语言风格记忆；失败、未调用或无足够材料时提供可复制稿，明确未保存。当前没有独立记忆回读工具，不生成路径、版本、哈希或回读回执；后续请求由框架加载当前值，不自动重写旧作品。

停用与替代按真实状态保留依据，候选不能因为保存成功自动生效。当前没有历史快照库或指定版本回滚；旧材料只有在实际可见且获准时才能作为当前修订依据，不能根据摘要补造完整旧版后声称恢复。

## 确认后的定位维护

定位仍是独立 `positioningReport`，按 [定位报告协议](positioning-report-views.md) 保留13项第一人称正文、事实／推演／设计／采用状态与真实缺口。局部纠正只复核实际依赖的受众、需求、价值、内容方向和边界，不重启十主题咨询，不清空其他成果或自动改变咨询完成状态。

通过同一原生工具仅提交获准的定位章节完整正文及实际元信息，保留同章有效旧内容和无关章节。工具成功才报告对应定位更新，风格与定位只成功一类时分别说明。查询已有报告只读，不因格式整理写回，不附送用户未请求的整份报告。重新专业定位时衔接实际已注册的深度定位，不假装本技能已执行完整咨询。

没有档案时，经确认或已有明确建档授权，可以用已讨论部分建立初版，未知维度保持未知，不补造完整人格与语言习惯。当前每个认证用户只有一份定位及一组风格，未提供账号／项目分组；歧义影响保存时只澄清必要对象，不跨用户或混合不同人的资料。方法包保持只读，不创建常驻任务或承诺跨平台自动同步。
