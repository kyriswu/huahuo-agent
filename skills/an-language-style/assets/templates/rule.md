# 单条表达偏好记录

填写模板，不属于本人样文或有效规则。只记录有用信息，不凑数量；背景理解与表达偏好分开。

- 编号：沿用稳定编号
- 类型：本人习惯 / 目标偏好
- 状态：有效 / 候选 / 停用 / 被替代
- 具体选择：同一意思下更自然的措辞、明确避用表达或局部句法
- 适用范围与例外：文体、交流对象、场景；必要术语、引文和原意如何保留
- 来源索引：本 Resource 已有或本次获准新建的逻辑 sourceId、lineage 与实际依据；不伪造数据库消息 ID、文件位置或哈希

以下分析留在 `languageStyleLearning` 的实际来源、observations 和 learningRecords，当前写作档案只保留有效选择、范围和来源索引：

- 短对照及理由：原表达 → 本人表达；区分内容修正与语言选择
- 支持与反例：独立证据、范围限制、尚未解决的冲突
- 状态与替代关系：生效、候选、停用或被替代的原因；保留原依据

检查这条偏好能否在保持原意时执行；不能要求固定主题、立场、归因、文章结构或结论。未出现的词不自动禁用，高频题材词不自动必用。单次改稿不自动推广为永久规则。
