# Huahuo skills

The active business skills live in the repository's `skills/` directory and
are registered directly on HuoX through Mastra's native `skills` option:
deep positioning, opening design, content uplift, situation design, prop
design, and language style. Their supporting methods are loaded with native
skill tools. Language style and its learning evidence use native resource
Working Memory alongside the positioning report.

Keep executable business integrations in the application/adapters boundaries;
do not duplicate skill text or user data in this placeholder directory. See
the root README for memory scope, creative workflows, and host adaptations.
